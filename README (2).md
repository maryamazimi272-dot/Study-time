# Study Time

[English](#english) | [Қазақша](#қазақша)

## English

A simple study planner for students. It keeps tasks, class schedule, a focus timer and exam progress in one place, plus short language courses (English, Russian, German), and tells you how many topics to study today.

Built with HTML, CSS and JavaScript. Open `index.html` to run it.

## Қазақша

Студенттерге арналған қарапайым оқу жоспарлаушысы. Тапсырма, сабақ кестесі, фокус таймері және емтихан прогресі бір жерде тұрады, ал бүгін қанша тақырып оқу керегін өзі есептеп көрсетеді.

Мүмкіндіктері: тіл курстары (ағылшын, орыс, неміс), дедлайндар, апталық кесте, Pomodoro таймері, емтиханға дайындық прогресі, XP мен деңгей жүйесі, қараңғы режим.

HTML, CSS және JavaScript-пен жасалған. Іске қосу үшін `index.html` файлын ашыңыз.
